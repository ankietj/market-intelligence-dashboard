# Market Intelligence Dashboard 🏛️

A public-facing, institutional-grade market intelligence terminal and presentation platform for Indian equities (NIFTY 50), institutional derivatives positioning, sector rotation, global macro indicators, and pre-market auction forecasting.

**Live Public Dashboard URL:**  
👉 **[https://ankietj.github.io/market-intelligence-dashboard/](https://ankietj.github.io/market-intelligence-dashboard/)**

---

## 1. Overview & Purpose

The **Market Intelligence Dashboard** is an evidence-backed web application built for investors, researchers, and market participants. It translates quantitative intelligence generated by the private `swing-trading-system` into an uncluttered financial terminal interface.

- **Zero Runtime Backend:** Operates as a 100% static React + TypeScript single-page application hosted on GitHub Pages.
- **Manual Publishing Only:** Strictly published via GitHub Actions `workflow_dispatch`. Zero automated cron refreshes or unmonitored deployments.
- **Point-in-Time & Critic Verified:** Every metric is backed by deterministic SHA-256 evidence hashing and independent Critic multi-agent audit.
- **Strict Data Sanitization:** Private source files, credentials, and internal paths are scrubbed prior to publication.

---

## 2. Dashboard Sections

The terminal provides 8 dedicated sections:

1. **Market Command Centre:** Executive summary of NIFTY 50, NIFTY Bank, India VIX, constituent breadth, institutional positioning, top 3 positive drivers, top 3 downside risks, and executive takeaway.
2. **Global & Macro Intelligence:** International benchmark performance (US, Europe, Asia), Brent Crude, USD/INR, US 10Y Yield, Dollar Index (DXY), and GIFT Nifty proxy spread.
3. **Institutional Intelligence:** FII/DII cash market turnover, participant-wise Index Futures open interest, FII Long/Short ratio, and contrarian short-squeeze alerts (< 25% FII longs).
4. **Sector Rotation & Stock Leadership:** Performance and relative strength across 19 sectors, cyclical vs defensive RS spread, leading/lagging clusters, and stock gainers/losers.
5. **Derivatives Intelligence:** Open Interest Put-Call Ratio (PCR_OI), Volume PCR, Option Max Pain strike, Call Wall (overhead resistance), Put Wall (downside support), and ATM Straddle volatility corridor.
6. **NIFTY Forecast & Pre-Open Auction Plan:** Version 1 Post-Close baseline forecast (directional probability distribution, expected range, classic & Fibonacci pivots) and Version 2 Pre-Open (08:30 IST) auction bracket guidelines.
7. **Risk & Event Monitor:** Macro systemic risk indicator, India VIX de-risking threshold gate, gamma flip levels, and scheduled economic catalysts.
8. **Daily Intelligence Report:** Authoritative 10-point cross-specialist market briefing synthesized by the multi-agent orchestrator with cross-domain agreements and divergences.

## 3. Technology Stack

- **Framework:** React 18 / TypeScript / Vite
- **Styling:** Tailwind CSS (Dark Terminal Theme)
- **Icons:** Lucide React
- **Hosting:** GitHub Pages (`actions/deploy-pages`)
- **Data Engine:** Python 3.12 / DuckDB / PyArrow / Pydantic (in private `swing-trading-system`)
- **Data Contract:** Versioned JSON schemas (`schemas/public_snapshot.schema.json`)

---

## 4. Local Development

```bash
# Clone the dashboard repository
git clone https://github.com/ankietj/market-intelligence-dashboard.git
cd market-intelligence-dashboard

# Install dependencies
npm install

# Start Vite local development server
npm run dev
```

Open `http://localhost:3000` to inspect the dashboard locally against the latest JSON snapshot.

---

## 5. Manual Publishing Workflow

Publication is strictly manual and governed:

1. In GitHub, navigate to **Actions** -> **Publish Market Intelligence Dashboard**.
2. Click **Run workflow**, optionally enter a publication note, and confirm.
3. The workflow executes schema validation, sanitization audits, static site compilation, and deploys directly to GitHub Pages.
